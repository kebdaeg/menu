ربط GitHub:

صفحة الأدمن بتحفظ التعديلات في ملف menu.json جوه الـ repository. محتاجة مفتاح (Token) من حسابك مرة واحدة بس، وبيتحفظ على الجهاز ده.

  1. GitHub ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token
  2. Repository access: Only select repositories ← اختار الـ repository بتاع المنيو
  3. Permissions ← Contents: Read and write ← Generate token، وانسخه هنا
